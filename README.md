<a id="开始使用"></a>
## 🧭 第一次来，从这里开始

1. **找对应课程与主题。** 从上方导航进入目录，点击 `.c` 或 `.cpp` 文件即可阅读。
2. **结合自己的题目理解代码。** 对照输入输出要求，先写出思路，再比较不同实现；课程要求可能随学期调整。
3. **挑一个文件单独运行。** 练习通常是独立程序，请使用对应的 C / C++ 编译器，不要把多个含 `main` 的文件一起编译。
4. **把发现留给后来者。** 遇到错误、边界情况或更清楚的解释，可以发起 Issue 或提交 Pull Request。

<details>
<summary><b>💻 想下载到本地？展开查看</b></summary>

可以在仓库首页选择 **Code → Download ZIP**，也可以使用 Git：

```bash
git clone https://github.com/Maximora-byte/swu-homework.git
cd swu-homework
```

单文件编译示例（已安装 GCC 的环境）：

```bash
gcc "2026秋季高级语言程序设计(C语言)/超星/helloworld.c" -o hello
```

编译后运行生成的可执行文件；Windows 下通常为 `hello.exe`，Linux / macOS 下可使用 `./hello`。其他题目可能需要输入数据或额外的数学库链接选项，请按源码与编译器提示调整。

</details>

## 🤝 参与共建

一处勘误、一段思路说明、一个边界测试，都能让这份资料更有用。

| 你想做什么 | 可以这样参与 |
| :--- | :--- |
| 提问或反馈错误 | 先搜索 [已有 Issues](https://github.com/Maximora-byte/swu-homework/issues)，没有相同问题再新建 |
| 改进现有内容 | Fork 仓库，在独立分支修改对应文件，提交 Pull Request |
| 补充课程或资料 | 先用 Issue 说明课程、学期与内容，再按现有目录风格整理 |
| 暂时不熟悉 Git | 直接在 Issue 中写清建议、文件位置与示例，也是一份贡献 |

### 提交前的小清单

- **放对位置：** 优先沿用“学期与课程 → 平台或主题”的现有结构；新增课程请同步补充首页导航。
- **讲清内容：** 说明适用学期、题目背景或知识点；代码修改附运行环境与输入输出示例。
- **自己检查：** 确认可编译、示例结果合理，必要时补充边界情况；不要上传编译产物。
- **控制范围：** 一次 PR 尽量围绕一门课、一个主题或一类修正，方便讨论与审核。

## 🌱 共享约定

- **尊重课程要求。** 参考代码用于学习与讨论，请独立完成需要独立提交的作业；引用他人成果时注明来源。
- **只分享有权公开的内容。** 教材扫描件、未获授权的课件与试题、受限制的课程资料不应上传。
- **保护彼此的隐私。** 提交前移除学号、联系方式、成绩、账号凭据等信息。
- **一起纠错。** 内容可能存在疏漏；如发现代码问题或涉及版权、隐私的内容，请通过 Issue 指明文件位置，避免再次公开敏感信息。
